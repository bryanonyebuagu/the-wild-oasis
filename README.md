# The Wild Oasis — Management App

An internal hotel operations dashboard built with React. Staff can manage cabins, reservations, guest check-ins, users, and application settings.

## Highlights

- Dashboard, booking list, booking detail, and check-in workflows.
- Cabin and user administration.
- Protected application routes and account settings.
- Server-state handling with TanStack Query and contextual notifications.
- Dark mode and responsive interface layouts.

## Tech stack

React, Vite, React Router, TanStack Query, Supabase, styled-components, React Hook Form, and date-fns.

## Run locally

```sh
npm install
npm run dev
```

Configure the required Supabase environment values for connected data and authentication. Keep credentials in local environment files and out of source control.
